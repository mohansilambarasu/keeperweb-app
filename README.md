Sticky Scripts - Notes App frontend project (Front-end)

This project is a simple yet functional notes-taking application built using React. It allows users to create, store, and delete notes seamlessly, offering a frontend interface for managing daily tasks or jotting down quick ideas.
URL : https://mohansilambarasu.github.io/keeperweb-app/

Features:

Add New Notes: Users can easily add new notes with a title and description.

Delete Notes: Notes can be removed with a single click, keeping the list organized.

Dynamic UI: The app dynamically updates the interface as notes are added or deleted, providing a responsive user experience.

Minimalistic Design: A clean and minimal design ensures that users stay focused on their notes.

Real-time Updates: Notes appear instantly when added or deleted without needing to refresh the page.

Responsive Design: The project is designed to work seamlessly on various screen sizes.

Technologies Used :

HTML , CSS: Provides the structure of the landing page. CSS here is used for an attractive appearance and to attain a Minimalistic design.

JavaScript , ReactJS: Manages the state of the application and provides functionality to the site.
